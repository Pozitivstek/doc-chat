# 📄 DocChat — chat with your documents (RAG)

**RU** — Загрузите PDF и задавайте вопросы. Ответы строятся только по найденным фрагментам и приходят со ссылками `[1] [2]` на страницы документа: клик по ссылке открывает исходный текст. Работает с Claude API; без ключа — в режиме «поиск без LLM».
**EN** — Upload a PDF and ask questions. Answers are grounded in retrieved passages and come with `[1] [2]` citations to the document pages; click a citation to see the source text. Uses the Claude API; without a key it falls back to retrieval-only mode.

Python 3.11+ · FastAPI · SSE streaming · BM25 retrieval · Claude · 97 tests

## Как это работает / How it works

```
PDF/TXT ─▶ текст по страницам ─▶ фрагменты ~800 симв. с перекрытием ─▶ SQLite
                                                                          │
вопрос ─▶ BM25 (ru/en морфология, порог релевантности) ─▶ top-k фрагментов ┘
                      │
                      ▼
      Claude: «отвечай только по <documents>, ссылайся [n]»  ─▶ SSE-стрим в браузер
```

- **Поиск без внешних моделей.** BM25 с лёгким стеммингом русского и английского: детерминированный, быстрый, без загрузки эмбеддингов. Слабые совпадения (< 35 % от лучшего) отбрасываются.
- **Ответ только по документам.** Если ничего не найдено, модель не вызывается: пользователь получает честное «ничего не нашлось».
- **Ссылки на источники.** Фрагменты нумеруются, модель обязана ставить `[n]`; номера вне диапазона игнорируются, клик по `[n]` подсвечивает исходный пассаж и страницу.
- **Многоходовой диалог.** Короткий уточняющий вопрос («а подробнее?») расширяется прошлым вопросом для поиска.
- **Режим без LLM.** Без ключа показываются предложения, совпавшие с вопросом, — приложение полезно и в таком виде.

## Безопасность / Security

- **Prompt injection.** Текст документов — недоверенные данные: он экранируется, не может закрыть `</documents>`, а системный промпт запрещает выполнять команды из документов.
- **Изоляция.** Документы привязаны к случайной HttpOnly-сессии (`SameSite=Lax`); чужие `doc_id` игнорируются.
- **Лимиты.** 10 МБ, 300 страниц, 5 документов на сессию, 20 вопросов в минуту; PDF проверяется по сигнатуре, не по расширению; зашифрованные и «сканы» отклоняются с понятной причиной.
- **XSS.** Интерфейс не использует `innerHTML`; CSP `default-src 'self'`.
- **Приватность.** Документы удаляются через `TTL_HOURS` (24 ч). В режиме Claude фрагменты уходят в Anthropic API — об этом сказано в интерфейсе.
- **Отказы модели.** Включён серверный фолбэк (`fallbacks: "default"`); `stop_reason: refusal` превращается в понятное сообщение.

## Запуск / Run

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env              # впишите ANTHROPIC_API_KEY (необязательно)
.venv/bin/python -m docchat       # http://127.0.0.1:8000
```

Демо-документ: `samples/dogovor-postavki.pdf` (пересоздаётся `python tools/make_sample.py`).
Примеры вопросов: «Какой срок действия договора?», «Сколько дней на оплату и какая пеня за просрочку?», «Какая гарантия на кофе?».

## Тесты / Tests

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest --cov=docchat
```

Покрыты: токенизация и стемминг, нарезка, BM25, PDF (включая кириллицу, шифрование, сканы), хранилище и изоляция сессий, лимитер, формирование промпта, стриминг и ошибки Claude (на подменённом клиенте), HTTP API и SSE.

## Структура / Structure

```
docchat/
  app.py        FastAPI: загрузка, чат (SSE), сессии, защитные заголовки
  llm.py        промпт, ClaudeAnswerer (стрим, фолбэк, ошибки), ExtractiveAnswerer
  search.py     BM25 + порог релевантности
  text.py       токенизация, стемминг ru/en
  chunking.py   очистка текста и нарезка с перекрытием
  pdf.py        извлечение текста, понятные ошибки
  store.py      SQLite, изоляция по сессии, TTL
  static/       интерфейс (чистый HTML/JS, RU/EN)
tests/
```
